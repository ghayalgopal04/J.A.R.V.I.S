# J.A.R.V.I.S.: Master Development Prompt

This repository adopts the J.A.R.V.I.S. master build specification as the source of truth for the project. The implementation is expected to follow the architecture, modules, security guardrails, testing requirements, setup guidance, and phase-by-phase delivery sequence defined in the J.A.R.V.I.S. master prompt.

The underlying project goal is to deliver a secure, modular, extensible AI desktop assistant for Windows with a React/TypeScript frontend, Python/FastAPI backend, SQLite persistence, provider abstraction, connector architecture, multi-agent orchestration, and safe Windows automation constraints.

The complete product scope is implemented progressively in the repository with explicit traceability and honest status tracking. Requirements that require unavailable credentials, hardware, or platform tooling are documented as partial, blocked, or not tested with the reason and next action included.
